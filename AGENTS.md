## Architecture rules
- Keep the campaign as one continuous index route with section anchors because the requested experience is one uninterrupted scroll narrative.
- Keep fictional product content in a browser-safe data module and compose the campaign from reusable sections because editorial interactions should share one source of truth.
- Use original optimized photographic assets and scoped GSAP transforms for bottle depth instead of claiming true 3D rotation because this preserves glass fidelity and mobile performance.
- Use native modal dialogs for collection details and the fullscreen mobile navigation because they supply keyboard focus containment and Escape dismissal.
